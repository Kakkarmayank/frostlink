# ❄️ Frostlink

**Frostlink** is a lightweight Python package that lets you connect to **Snowflake** seamlessly —  
with **zero manual setup**, built-in **Streamlit UI** for configuration, and support for **Pandas**, **SQL**, and **PySpark** workflows.

---

## 🚀 Features

✅ One-time setup — Automatically creates `snowflake_config.json`  
✅ Streamlit UI for easy connection setup (no manual editing)  
✅ Works with Pandas (`read_sql`, `read_table`)  
✅ PySpark support for large datasets  
✅ Secure authentication via SSO (`externalbrowser`)  
✅ Built for teams — deploy and share as a package
